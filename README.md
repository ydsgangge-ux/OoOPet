# OoOPet 桌宠

**把喜欢的角色视频，变成桌面宠物。**

不用建模、不用绑骨、不用学 Live2D。一段视频放进去，抠掉背景，就能站在桌面上陪你。

## 三步做好

1. 下载 Releases 里的 `桌宠.exe`，双击运行
2. 右键 →「打开素材目录」，把视频放进对应文件夹
3. 右键 →「一键抠视频」，实心背景自动变透明

支持 `mp4 / mov / mkv / avi / webm / gif / apng / png`。已经有透明背景的 webm、apng 可以直接用，不用抠。

## 一个角色，多种表情

每个状态一个文件夹：待机、忙碌、充电、低电量、开会、写代码、看视频、困了、被拎起……

桌宠会根据电脑状态自动切换，也能在右键菜单里手动选。

## 小细节

- 按住拖动会播放「被拎起」动作，松手回到当前状态
- 单击戳一下，随机反应
- Ctrl + 滚轮缩放，位置和大小会记住

## 从源码运行

需要 Python 3.10+，双击 `启动桌宠.bat`，缺依赖会自动安装。
