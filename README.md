# OoOPet 桌宠

一个会感知电脑状态的桌面宠物。CPU 高负载、插电、低电量、开会、写代码、看视频、深夜没动……都会换成对应表情。

## 使用

下载 Releases 里的 `桌宠.exe`，双击运行。右键桌宠可以：

- 切换动作、调整大小
- 打开素材目录
- 一键抠视频（把实心背景视频变成透明）
- 开关系统状态联动

素材放在 `%APPDATA%\DesktopPet\pet\<动作>\`，支持 webm / apng / gif / mp4 等。某个状态没有素材时，会自动回落到相近的表情。

## 从源码运行

需要 Python 3.10+，双击 `启动桌宠.bat`，缺依赖会自动安装。
